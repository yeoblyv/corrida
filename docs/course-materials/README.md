# Course materials

Original materials distributed by the course, archived here so every fact
this repository states about the assignment (deadlines, group roster,
hardware, maze rules) traces back to a stable, in-repo file instead of an
email attachment or a Downloads folder.

This is a practical archive, not the citation itself. Anything here is
undistributed course material — cite it as **personal communication**
per [docs/REFERENCES.md §4](../REFERENCES.md#4-personal-communications--course-material),
never as a numbered/author-date reference-list entry.
